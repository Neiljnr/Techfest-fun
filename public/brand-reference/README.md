# Jos TechFest 2026 visual reference

Use these supplied artboards as the design source for future event pages and materials:

- `techfest-2026-artwork.webp` — full event artwork and identity variations.
- `techfest-2026-key-art.webp` — robot and portrait key art.
- `techfest-2026-sponsor-board.webp` — supplied sponsor logo board, used in the home screen marquee.
- `techfest-2026-sponsor-marquee.webp` — presentation crop used by the moving strip.

Keep the visual direction consistent with the artboards: deep forest green and black, vivid TechFest green, white display type, futuristic technology imagery, circuit and network motifs, and small orange/lime accents. Preserve the supplied logos and their proportions when presenting partners.
