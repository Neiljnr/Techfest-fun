# TechFest Quest

A browser-based prototype for attendee networking and event quests.

## Prototype limitations

- Profiles and scores are stored in the browser and are not authenticated or verified.
- Gmail addresses are checked for format only; ownership is not verified.
- Referral points and organizer tools are disabled because this prototype has no trusted backend or staff authorization.
- Do not use prototype scores for official event results.

Production use requires server-side authentication, role authorization, verified check-ins, and a shared score ledger.
